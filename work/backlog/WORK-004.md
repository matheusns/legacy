# Deliver the reviewed application shell

This is the presentation-only part of LEGACY-WORK-004. **Predecessors:** LEGACY-WORK-003 (application shell) and LEGACY-WORK-016 (authenticated, deterministic UX capture readiness).

The UX role refines the approved first-slice presentation and interaction states; it does not implement API fixture loading, change access-control rules or approve visual baselines.

## Acceptance criteria

- [ ] The running shell preserves the five destinations, Auto/Mobile/Desktop behavior and accessibility requirements while improving design fidelity against candidate visual references.
- [ ] Keyboard/touch alternatives and reduced-motion behavior are inspected and independently exercised.
- [ ] Candidate desktop and phone captures retain source, fixture, profile, browser, and clock provenance from the accepted WP-016 setup.
- [ ] The owner and UX reviewer separately decide whether any reference may be approved and pinned (DEC-010). No auto-approval.
